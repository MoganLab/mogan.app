Mogan STEM v2025.2.x 版本更新日志 ​

说明：Liii STEM 是 Mogan STEM 的商业版，会在开源版的基础上提供账号登录、AI 等增值能力。更多细节见Liii STEM：v2025.2.x

⭐️ 全新功能和亮点 ​

  1. Python 插件渲染升级：支持将 Matplotlib 图像、SymPy 公式、Pandas 表格渲染为可编辑内容，并支持插入折叠的可运行代码块。
  2. 结构化搜索与替换：支持对文本、公式、符号、矩阵等结构内容进行搜索与替换。
  3. 黑夜模式与批注：界面与文档黑夜模式；批注支持插入、折叠/展开，并支持公式等内容。
  4. 性能与稳定性：优化数学模式编辑性能；排版引擎优化（中文标点压缩）；修复 Windows 在 125% 缩放等情况下菜单栏消失问题等。
  5. 多标签页置顶：支持将标签页置顶（类似 Chrome 浏览器体验）。
  6. 矢量图与图片格式：原生支持 PDF 矢量图；新增 WebP 图片支持。
  7. 插件生态与环境支持：完善 Python/Maxima/Gnuplot 等插件支持，并支持 conda 环境。
  8. 文档与输入增强：页码设置更灵活；新增更多符号与 Tab Cycling 输入（\textendash/\textemdash、LEGO 符号等）；新增下划线与删除线等。（Liii STEM 另提供 AI、OCR 等增值能力）

🌟 总结 ​

v2025.2.x 系列聚焦于“可运行插件 + 编辑与排版体验 + 格式支持”的全面提升：Python 插件渲染链路升级让图像/公式/表格可直接编辑，同时补齐 PDF 矢量图与 WebP 等格式能力，并在结构化搜索替换、黑夜模式、批注、中文排版与跨平台稳定性等方面持续迭代。商业版 Liii STEM 会在此基础上提供账号登录、AI、OCR 等增值能力。

🔧 更新日志 ​

Mogan STEM v2025.2.3 (2026/01/06) ​

  1. 更现代化的结构化搜索与替换：支持公式、符号、矩阵等结构内容。
  2. 全新黑夜模式：界面与文档均支持黑夜模式。
  3. 全新批注功能：支持插入批注并折叠/展开，批注内容支持公式等。
  4. 排版引擎优化：中文标点压缩。
  5. Tab Cycling 增强：新增 mathcal/mathbf/mathfrak 输入方式；为 n 增加 \nabla 变体。
  6. 图片悬浮菜单：支持布局快速调整；（Liii STEM）支持 OCR 识别。
  7. nbsp 显示优化：不换行空格默认采用不可见颜色，可调整。

Mogan STEM v2025.2.2 (2025/12/10) ​

  1. （Liii STEM）接入高速版 DeepSeek V3.2，支持与公式直接交互。
  2. 极大优化数学模式编辑性能，修复 Tab Cycling 卡顿问题。
  3. 修复 Windows 在 125% 缩放等情况下菜单栏消失的问题。
  4. 表格环境支持任意角度旋转。
  5. 更改可折叠代码块的背景色。
  6. 新增下划线与删除线（可配合 Comment 插件使用）。

Mogan STEM v2025.2.1 (2025/12/03) ​

  1. Python 插件渲染升级：Matplotlib 绘图、SymPy 公式、Pandas 表格渲染为可编辑内容；支持折叠的可运行代码块并保留源代码。
  2. 插件与环境：支持 conda 环境；完善 Maxima、Gnuplot 等插件展示与渲染体验。
  3. 格式与图片：原生支持 PDF 矢量图；新增 WebP 图片支持。
  4. 多标签页：支持多标签页置顶。
  5. 编辑器体验：光标颜色/闪烁、选中背景色等优化；页码设置更灵活。
  6. 其余更新：新增多种符号与 Tab Cycling 输入（\textendash/\textemdash、LEGO 符号等）；模式工具栏新增附录（Appendix）选项与快捷键。
  7. 商业版：同步发布 Liii STEM v2025.2.1（支持登录，开启公测）。
