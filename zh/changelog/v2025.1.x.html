Mogan STEM v2025.1.x 版本更新日志 ​

说明：Liii STEM 是 Mogan STEM 的商业版，会在开源版的基础上提供账号登录、AI 等增值能力更多细节见Liii STEM：v2025.1.x。

⭐️ 全新功能和亮点 ​

  1. 现代化 UI 与主题：新增 Liii / Liii Dark 主题与全套矢量化图标，界面更统一。
  2. 底层升级：升级到 TeXmacs 2.1.4，并内嵌自研编程语言 goldfish scheme。
  3. Tab Cycling / 智能补全：文本、数学与宏命令补全；积分/求和/集合符号与数学字体（\mathcal/\mathbf/\mathfrak 等）支持 Tab 循环输入。
  4. 多标签页体验升级：新增/切换标签页快捷键（macOS Cmd+T、Cmd+1-6），并提升多标签页管理与稳定性。
  5. 导出与文件处理增强：PDF 导出增加进度与完成提示；按文件头识别图片格式减少导出失败；保存/另存为/打开对话框的可选文件格式展示完善。
  6. 稳定性与性能优化：启动、编辑、渲染性能优化；修复 </> 叠影、中文省略号卡死、复制崩溃、调试窗口无法打开等问题。

🌟 总结 ​

v2025.1.x 系列围绕“更现代的界面、更快的输入、更可靠的编辑体验”持续迭代：主题与图标整体升级，Tab Cycling 覆盖文本/数学/宏与常用符号输入，多标签页与导出体验加强，并持续打磨稳定性与性能。

🔧 更新日志 ​

Mogan STEM v2025.1.4 (2025/10/06) ​

  1. 输入增强：积分/求和/累乘/集合符号 Tab 循环输入；数学字体 Tab Cycling 优化；新增 \mathscr 宏支持。
  2. 导出与图片：PDF 导出增加进度提示并在完成后询问是否打开；图片格式按文件头自动识别，避免后缀与内容不一致导致导出失败。
  3. Emoji：支持通过 :smile: 等方式快速插入 Emoji。
  4. 体验与兼容：非 macOS 平台 Meta 键显示为 Win/Super；保存/另存为/打开对话框的格式选项完善；macOS 兼容性修复。
  5. 修复：中文省略号插入卡死、</> 叠影、verbatim 不能换行、复制大段文本崩溃、调试窗口打不开等。

更多细节见Liii STEM：v2025.1.x

Mogan STEM v2025.1.1 (2025/08/21) ​

  1. 项目更名：Mogan 更名为 Mogan STEM，并发布 v2025.1.1。
  2. 底层升级：升级到 TeXmacs 2.1.4，并内嵌自研编程语言 goldfish scheme。
  3. 主题与图标：新增 Liii / Liii Dark 主题；大量图标升级为矢量并统一风格；工具栏补充高亮等入口（部分 AI 入口为商业版 Liii STEM 独有）。
  4. Tab 补全：数学字符 Tab Cycling；label/单词补全；宏命令补全。
  5. 多标签页：macOS Cmd+T 新建标签页、Cmd+1-6 切换；新增窗口附着/脱离管理并修复多标签页相关问题。
  6. 排版与编辑：语义块采用欧式编号风格并新增 Assumption 环境；乘号默认显示 × 且可用 Tab 切换；新增多重积分相关 LaTeX 宏；结构化搜索替换窗口嵌入为辅助窗口；魔法粘贴与 Emoji（内测）支持增强。
  7. 性能：启动、编辑与渲染更流畅。

更多细节见Liii STEM：v2025.1.x
