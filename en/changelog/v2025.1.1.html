Mogan Renamed to Mogan STEM, v2025.1.1 Officially Released ​

We are officially releasing Mogan v2025.1.1 and renaming the project to Mogan STEM — a modern editor for scientific and engineering work.

The new version brings a completely new UI, intelligent completion, and significant improvements in stability and performance. Download it and give it a try.

  • Release page and downloads: https://github.com/XmacsLabs/mogan/releases/tag/v2025.1.1

Mogan STEM's underlying system has been upgraded to TeXmacs 2.1.4 and embeds the self-developed programming language goldfish scheme.

This document records only the Mogan community’s work and does not include changes from GNU TeXmacs 2.1.2 to 2.1.4.

What is Mogan STEM ​

Mogan STEM is an intelligent writing and typesetting tool designed for science and engineering. It integrates powerful formula editing, automatic typesetting, AI assistance, and visual recognition capabilities. Whether you’re preparing lessons, writing lecture notes, or taking class notes, it can greatly improve your efficiency.

  • One-click typesetting, standardized and beautiful: Just input your content, and Mogan STEM automatically produces structured, standards‑compliant notes, eliminating typesetting headaches.
  • Ultra-fast mathematical formula input: Offers many easy‑to‑remember formula input methods with WYSIWYG editing—no code needed—making it far more efficient than .
  • Magic Paste: Copy content from ChatGPT, DeepSeek, Zhihu, etc., and it is automatically formatted, saving you from manual typesetting.
  • Balancing standards and innovation: Mogan STEM provides a complete workflow from in‑class note‑taking to post‑class organization to paper writing, helping students build academic rigor and encouraging innovation.

Faster, more standardized, and more efficient than handwriting! Mogan STEM has an extremely low learning curve. New students can get started quickly, moving from “messy draft notebooks” to producing results like this in about a week of practice (notes by a student from the Department of Statistics at Southern University of Science and Technology, created with Mogan STEM): https://liiistem.cn/library/notes/STAT850.html

By Yifan Lu and Shiqi Yu

Mogan STEM 1.1 introduces two new themes: Liii and Liii Dark (the dark version of Liii). The Liii theme will be the default theme for Mogan STEM and Liii STEM going forward.

You can revert to the old theme via Edit -> Preferences -> User Interface Theme.

Interface Update Summary ​

Summary:

  • Removed icons for two printer fonts. Users can now use the F6 and F7 shortcuts, or the commands \texttt and \textsc, to access printer font environments.
  • Added icons for the highlight environment in text mode.

  • Added icons for inserting built‑in AI blocks (exclusive to Liii STEM; in Mogan this icon redirects to the Liii STEM website).

  • Converted many raster icons to vector graphics.
  • Updated background color schemes for a more unified style.
  • Reworked most icons to improve recognizability.
